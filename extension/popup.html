补充我的历史回复 打开 X 通知

默认关闭，仅“主页 → 为你推荐”生效。自己的帖子和回复直接隐藏；别人的原帖需评论过（含楼中楼），并且给这篇原帖点过红心，才隐藏。只做一项或记录待确认仍保留。关闭开关恢复显示，记录不删除。

回复框打开时暂不折叠或恢复，关闭后生效。新加载帖子照常判断；“正在关注”和通知页不受影响。

通知回复框底部显示原帖、文字/红心状态、双方评论原帖数和 NEW，沿用下方统计口径。「他的主页」在新标签页打开当前评论者主页，保留草稿；未确认账号时不可跳转。

通知页可在标题栏切换“隐藏已回且已点”，默认关闭，与主页开关独立。按同一原帖、同一个人的文字和红心标签筛选，点赞、关注等聚合通知保留。阅读时已显示卡片保持位置，后续变化点击右侧“整理列表”后应用；按钮始终显示，没有更新时置灰，位置不随滚动变化；关闭空回复框不会自动收起当前卡片。关闭筛选即可恢复。

两项同时显示，不用切换。按同一原帖、同一个人判断，点赞和文字回复分别记录。

蓝色“我原帖”，紫色“别人原帖”。“我评他 / 他评我”分别统计评论对方的原帖数，同帖多次只算 1。标签保持固定行高，NEW 固定在末尾；窄处可横向查看其他标签。

连续回复：发送并下一条 / 跳过

在通知或主页的“为你推荐”“正在关注”列表点开任一条的小评论按钮。写好后点“发送并下一条”，确认发送成功并保存本地记录后自动打开下一条；X 原来的回复按钮仍只发送本条。切换页签结束本轮，不跨列表继续；已发出回复的成功回执仍会保存。

“♡ 点赞 / ♥ 已点”只操作当前正在回复的那条帖子；再次点击可取消。它与发送、跳过独立，不自动点赞，也不增加评论次数。复用 X 原生红心和成功回执保存记录；按钮以当前帖的原生状态为准，失败会随 X 回滚。原帖卡片移出列表时禁用，避免误点。

下一条从当前页面已加载的卡片中选择，不限于当前条下方。通知略过同一原帖里已文字回复过的人；主页原帖略过自己的帖子、已经评论过的原帖（含楼中楼）。本轮已处理的不重复，仅点过红心的仍展示。

主页“为你推荐”和“正在关注”都支持连续处理；自定义页签暂不启动，但照常回复仍会保存。普通、长评论以及原生回复都使用同一保存流程；不需要额外进入详情页。主页不插入逐条标签，避免撑高列表。

“跳过”只跳过本轮，不标记已回复。有未发送内容时优先保存到 X 草稿；无法确认保存时暂停，让你核对后继续。手动关闭回复框可退出连续处理。

只处理当前页面已加载的内容，不自动翻页补抓。新消息不会打断编辑，下一步时已加载的也可选。卡片移出页面后可改选其他已加载项；切换页签或账号结束本轮。发送失败或结果不明会停下，不自动重发。

使用 XReply 时，先按 Tab 接受要发送的内容；识别到逐字填入或改写期间会暂时禁用新按钮，完成后恢复。

统计口径与“待确认”

顶部总览：文字回复按“同一原帖、同一个人”计 1 组，红心按已点赞的帖子计条数；均为当前账号的本地记录。

原帖指整段对话最初的帖子，楼中楼沿用该原帖的作者归属。

“我评他”是你评论过他的几篇原帖；“他评我”是他评论过你的几篇原帖。同一篇下多次评论（含楼中楼）只算 1 篇。在自己或第三方原帖下回话、点赞不增加对应方向的数字。

NEW 只标他首次评论你原帖的那条通知，且必须“我评他”为 0；后续评论不重复标新。点赞或你在自己原帖下回复他不影响 NEW；你评论过他的原帖后，不再标 NEW。

“文字-已回”“红心-已点”各自查找你在同一原帖里对同一个人的回复、点赞依据，不跨原帖沿用。点击标签可查看依据。

打开自己的“回复”页，向下浏览近期回复。已加载的回复会自动记住，新发送成功的回复也会记录。

正常浏览通知和帖子即可补充页面返回的红心状态。点赞成功后自动记录，取消点赞后更新对应记录。

“待确认”表示目前没找到依据，不代表从未操作。手机或其他浏览器里的操作，需要在此浏览器加载后才能识别。

所有数字和 NEW 仅依据本地已读取记录；原帖作者未确认时不计入原帖数，确认后补计。0 不代表历史上从未操作；记录到期或淘汰后，统计可能减少。不额外抓取完整历史。
