互动历史保留在本机。开启 API 后，可在回复框点击「推荐评论」生成并填入一条。扩展弹窗的「自动 AI 补全」默认关闭，手动开启后才在空回复框生成三条候选；改写另发送当前草稿。没有新增 X 抓帖请求。Key 仅保存在此扩展本地，不使用 Chrome 同步。

自动追加 /chat/completions，支持 HTTPS 或 localhost / 127.0.0.1 HTTP 服务。
支持变量 ${post}。可粘贴你自己的原有 Prompt，输出用 <reply>...</reply> 包裹。
支持 ${post} 和 ${draft}。默认模板为独立编写，需原样保持写作风格时请填入你自己的 Prompt。
