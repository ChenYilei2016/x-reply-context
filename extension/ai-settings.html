AI 设置 · 自带 API

分三部分：先在「API 连接」里放好地址和 Key，再给「X 自动回复」和「创作台」的每个功能选连接、填模型。同一个连接可以给不同功能用不同模型。Key 只保存在此扩展本地，不使用 Chrome 同步。开启前请停用原来的 XReply，避免两套插件同时生成。

① API 连接
连接只包含地址、Key 和默认模型，最多 10 个。各功能在下面选择用哪个连接；功能的模型留空时用这里的默认模型。
可填 Base URL 或完整的 /chat/completions 地址。支持 HTTPS 或 localhost / 127.0.0.1 HTTP 服务。出图请求发往同一 Base URL 下的 /images/generations。

仅适用 OpenAI 官方地址。快速模式费用高于标准模式，实际可用性及处理等级由 OpenAI 决定；不会自动重试或切换。
按连接保存，仅向 OpenAI 官方地址传 reasoning_effort。强度越高通常耗时和推理用量越多。
② X 自动回复
开启后可在回复框点「推荐评论」生成并填入一条。扩展弹窗的「自动 AI 补全」默认关闭。

二次润色
润色接收当前帖正文和刚生成的回复。润色成功后填入结果，超时或失败时填入首稿。

③ 创作台
创作台不受「开启 AI 回复」开关影响。改写和出图提示词用「成稿」的模型；配图的模型是出图模型（如 gpt-image-2、gpt-image-2.5-flare；gpt-image-1 已停用），gpt-image-2 及之后按精确比例出图。各任务的写作要求在写作台「写作设置」里改。
