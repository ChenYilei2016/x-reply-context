写作台

粘贴内容或链接 → 改写或找角度 → 3 个候选 → 编辑 → 发布、配图。发布仍由你在 X 上点。

    你可以这样使用
    • 直接粘贴正文，按原内容改写；只写一个标题或事件，也可以找角度。
    • 粘贴文章链接会自动读取正文（第一次需要授权读取网页）；正文和链接可以混着写，最多 3 个链接。
    • X 帖子链接读不了（需要登录）：在 X 上点帖子下的「改写」「选入」，会直接带进来。
    • 在选题雷达或 X 上「选入」的素材显示在上面，可以和粘贴的内容一起融合。
