# 《回一句谢谢，回成了死循环》制作源

面向 B 站的 1920×1080 横版宣传片。参考用户提供的开发日志在叙事上的反差、自嘲、停顿，以及“大字分镜 + 合成旁白 + 截图 + FFmpeg”的制作方法；文案与画面围绕「回过了」重新创作。

- `storyboard.json`：分镜、逐句旁白和字幕；可直接改文案。
- `make.py`：本地渲染、配音、合成、字幕及封面生成。
- `assets/`：来自本项目 README 的虚构账号演示截图；没有复用参考游戏画面。
- `build/`：可再生的语音、画面和分段视频，不提交 Git。
- `out/`：成片、封面、字幕和构建信息，不自动上传。
- `publish.md`：标题、简介和标签草稿。

需要 macOS `say`、`ffmpeg`、`ffprobe`，以及 Python 的 Pillow。可使用 Codex 本机已有的 Python 运行时，无需为本项目安装新依赖。

```sh
python3 make.py --prepare   # 先生成分镜预览、配音和时间表
python3 make.py             # 完整合成，复用已生成的配音
```

只生成本地文件；不会登录平台、投稿、提交或推送仓库。画面中的状态说明以 0.4.1 为依据，计数单位是不同原帖数，NEW 不代表新增关注。
