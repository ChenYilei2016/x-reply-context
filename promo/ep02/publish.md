## 简介
本视频旁白为 AI 配音（macOS 语音），画面由脚本生成；账号与对话均为虚构示意。

「回过了」是一个开源 Chrome 扩展，帮你在 X（Twitter）通知里看清互动记录、逐条处理回复：
- 点赞 / 关注消息默认隐藏，转发可选
- 文字-已回、红心-已点、我评他 / 他评我、NEW 标签
- 六组快捷短语（Option/Alt+1～6），可选自带 API 的 AI 推荐（Option/Alt+Q）
- 「点赞发送下条」：先赞后发，成功后再到下一条；失败就暂停
- 「伴随主页」：旁边打开对方主页，左边通知和草稿不动

每条回复由你阅读并确认发送，互动记录保存在本机。网页脚本接入存在平台规范风险，请先阅读 README 中的「使用建议与平台风险」；不建议用于批量引流。与 X 官方无关联。
