# 0.15.1 通知回复框本地原帖摘要

通知回复框在互动标签下显示固定两行的原帖文字摘要，使用已有缓存（最多200字符）。换行压缩为空格，过长内容截断显示；鼠标停留可查看缓存摘要。没有正文显示「原帖内容暂未缓存」，本地读取失败显示「原帖内容暂不可用」。不加载媒体，也不主动请求或补抓原帖。

复用回复框已有的CLASSIFY调用，仅该调用要求返回原帖文字，按rootId从后台内存缓存直接查找；普通列表分类不携带正文，不新增IndexedDB读写或X接口。仍保留原帖链接，用于用户需要完整内容时自行查看。

摘要区域固定36px，不随读取、缺失、失败或内容长短变化高度。沿用原有对象/修订号检查，快速跳过和慢响应不会把上一条原帖摘要写到下一条回复框；底栏重建后重新创建摘要。

60项Node检查通过，包含普通分类不携带正文、回复框取得真正原帖文字、根正文缺失时不借用评论正文。生产回复框代码的本地浏览器回归13/13通过，包含双方原帖、楼中楼、读取失败高度、快切慢响应及底栏重绘；见 [回归结果](composer-excerpt-0.15.1.json) 和 [虚构页面截图](composer-excerpt-0.15.1.png)。

源码、安装包及原安装目录同步为0.15.1。用户重载后在真实通知页打开一个回复框：已显示缓存原帖文字，摘要高36px、行高18px；确认编辑器为空且无附件后关闭，回到通知页，scrollY保持0。真实正文与截图仅存仓库外，公开[指标](live-excerpt-0.15.1.json)不含账号正文。未对真实账号发送、点赞或关注。本次发布包括源码、README、安装包和验证记录；无关promo目录保持不动。
