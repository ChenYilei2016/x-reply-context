# 0.13.0 独立关注过滤与紧凑弹窗

## 行为

扩展弹窗增加「通知自动隐藏关注消息」，默认开启并独立保存；已有手动关闭的选择保留。复用既有通知事件识别、单轮快照、空闲调度和阅读区保护，没有新增接口或计时器。

- 单人、多人“关注了你”均支持；点赞原帖、喜欢回复及多人点赞仍由原点赞开关控制。按原生事件图标识别，不根据正文文案猜测。未知结构、缺少稳定时间字段保留。
- 开启或继续浏览后，空闲10秒只隐藏视口下方600px以外的通知，当前及上方保持位置。点赞与关注每轮合计最多100条；即使预算耗尽，两个过滤器都消耗本轮机会，补位不会启动另一轮。
- 回复框、后台和离页时暂停，真实用户交互后重新等待；布局 scroll、新消息、DOM 更新不能重新授予清理机会。手动整理也消耗本轮自动机会。
- 关注开关开启时，「整理列表」可一次清理已加载关注，即使完成评论规则关闭也可用。关闭关注开关只恢复它隐藏的关注通知，点赞与评论规则保持原选择；回复框打开时延迟恢复。
- 只隐藏本地显示，不删除通知、不取消关注或点赞、不发送内容。X 自身可能为本轮补位加载数据，但扩展不追着连续清理。

弹窗保留三项开关和简短提示，详情放在各卡片右上角，默认收起。通知整理、标签、连续回复和统计说明也按需展开。原通知标题栏的三个按钮和宽度不变。

## 验证

- Node 58 项通过，新增关注单人/多人、未知图标、同轮100条共享预算、补位不重启、独立关闭恢复、回复框暂停、关注手动整理、弹窗独立保存和点赞文案变体覆盖。
- fetch / XHR 的24项接口入口回归通过，错误记录及关闭空框后误隐藏均为0。
- 本地浏览器使用真实10秒计时，4/4通过：约10.28秒后150条关注只隐藏100条，再等11秒，余下50条及新增关注均保留；画面内评论 top 始终为11.5px，三个按钮坐标不变，点赞和评论保留，关闭后恢复。见 [验证数据](automatic-follows-0.13.0.json)。
- 弹窗使用实际 HTML/CSS/JS 与虚构统计渲染，默认高度599px，三个开关、七处详情均默认收起。已检查详情展开与收起，不触发开关。见 [紧凑弹窗](popup-compact-0.13.0.png)。
- 真实 Chrome X 通知页确认了关注事件的人形图标、稳定 datetime 和摘要结构。仅做读取，没有操作真实关注、点赞或发送。

新过滤行为与计时使用本地模拟 X 验证，真实页面的整体效果仍需重载扩展、刷新 X 后确认；X 自身的插入、媒体和排序变化不由扩展控制。README、安装包及原安装目录同步到0.13.0；本次提交到本地 Git，未推送。

## 默认值调整

点赞和关注过滤均改为默认开启；没有设置记录时生效，明确保存的关闭选择仍保留，弹窗与内容脚本读取口径一致。上方测试及截图来自本次默认值调整之前；按用户要求，这次不运行测试或浏览器验收，仅重新打包并替换原扩展目录。
