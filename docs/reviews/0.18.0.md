# 0.18.0 自动换批验证

## 行为边界

- 默认关闭。只在为你推荐、通知回复框底部显示，默认随机 10～20 条，每轮固定目标；区间支持 1～1000。
- 通过组合按钮或 Option/Alt+Enter 成功发送并保存后计数；重复回执去重，跳过、失败、原生单独发送不计。
- 到达目标后仍完成当前点赞流程，再进入 `/home`。通知页也进入为你推荐，只打开一条已加载、未回复且可确认对象的帖子，不自动发送。
- 草稿、可见弹窗、后台页面阻止刷新；换账号取消续接。刷新后的续接最多等待 15 秒，没有合适帖子或读取失败就停止。
- 每标签页使用一次性会话标记，消费后立即移除，最长有效 120 秒；关闭标签页清理。完整手动刷新不重放，重新计数。

## 性能与状态

复用现有控件刷新调度与本地批量分类；没有新增轮询、X 数据接口、自动分页或重试。候选最多取当前挂载的 100 张卡片，同一候选与数据版本不重复分类。成功回执集合最多 1000 项。仅开关与区间持久化，进度留在当前页面内存，续接标记放在扩展会话存储。

新增配置行固定高度，不在计数时增删控件。达到目标后的整页导航是显式开启功能的预期行为，不维持旧通知页滚动位置。X 自身正常页面加载仍会发出请求。

- `npm test`：126/126 通过，其中自动换批模块 9 项，覆盖成功去重、两入口范围、随机边界、草稿/后台、异步竞态、账号与配置变化、标记隔离与过期、空候选/超时停止。
- Chrome 本地演示页：6/6 通过。使用生产换批模块和后台标记代码、模拟 X 回执；从通知真实刷新到本地主页，验证只打开一次、标记消费、无自动发送、无草稿串入、再次手动刷新不续开，以及配置行高度稳定。
- 未在真实 X 执行评论、点赞或消耗 AI API；本地模拟不等同于真实 X 页面验收。安装目录更新后仍需手动重载扩展并刷新 X。
