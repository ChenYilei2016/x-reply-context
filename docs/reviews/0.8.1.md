# 0.8.1：撤回点赞通知隐藏试验

用户在试用“隐藏点赞通知”后反馈列表刷得太快，要求移除此功能。大量点赞通知收起会改变列表补位和加载表现，本次不继续扩展该筛选。

- 删除独立按钮、点赞事件图标识别、聚合通知折叠与设置读写；当前代码不再读取或使用试验设置 `hideLikeNotifications`。
- 运行文件以已验证的 0.7.0 安装包为依据恢复，版本更新为 0.8.1；保留“隐藏已回且已点”、主页筛选、手动红心与连续回复。
- 点赞和关注聚合通知正常保留；已有互动记录、主页设置与通知完成项设置不清空。运行中的试验开关已确认关闭。
- 试验代码、安装包与检查资料移到仓库外的本机归档，不随这次 Git 提交发布；旧版本验证记录继续保留。

移除后核对全部 40 项逻辑检查，并核对最终安装包与原安装目录文件一致。替换文件后仍需重载扩展、刷新 X，才能使已打开标签页加载新代码；不把文件覆盖当作已完成运行时更新。
