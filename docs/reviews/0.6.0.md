# 0.6.0：主页可选隐藏自己的内容与完成项

扩展弹窗增加“主页隐藏自己的内容及已完成原帖”，默认关闭；使用 `chrome.storage.local` 独立设置保存，在当前 Chrome 的 X 标签页间生效。互动缓存格式和已有记录不变。

## 判断口径

- 仅“主页 → 为你推荐”生效。自己的原帖及回复直接折叠；别人回复自己原帖的卡片不会仅因原帖归属而被隐藏。
- 别人的原帖需同时存在当前账号评论过该原帖的依据（含楼中楼）与原帖本身的已点赞依据。别人的回复卡片不纳入此完成项规则。
- 同一对话中其他回复的点赞不能代替原帖点赞；仅评论、仅点赞、证据不全保留。原生回复与自定义连续回复共用既有成功保存路径。
- 关闭开关、离开为你推荐、切换账号时恢复相应显示。回复框打开期间暂缓折叠及恢复，关闭后再应用。未删除任何帖子、互动记录或 X 列表节点。

## 列表与资源控制

`home-filter.js` 负责筛选和“为你推荐”识别，连续回复入口复用该识别；连续回复跳过已折叠卡片。每次只处理已挂载卡片，按最多 100 条一批本地分类，不请求历史、不主动滚动。

使用 1px 可测量的空卡片配合 X 原生虚拟列表测量，避免删除原生节点。列表重绘复用 ID、数据更新期间的异步结果、账号与页签变化均检查，防止旧判断作用于新卡片。完成项折叠本身会产生补位，不能保证 X 自身排序与媒体加载不改变位置。

## 验证依据

- Node 逻辑检查 40 项通过。新增覆盖自己的原帖/回复、别人原帖的两项必要依据、同对话其他帖点赞、账号隔离、开关/页签恢复、回复框暂缓、节点复用、取消点赞、100 条分批及过期异步结果。
- 本地浏览器验证了原生回复保存后仍参与筛选，不需要“发送并下一条”；原帖点赞成功保存且关闭回复框后才折叠。只点赞的原帖保留，关闭开关和切换“正在关注”恢复。见 [本地记录](../home-filter-0.6.0.json)。
- 增加隐藏自己后，本地再次验证自己的原帖和完成的 Alice 原帖均折叠为 1px，其余三张卡片保留。见 [包含自己的结果](../home-filter-with-own-0.6.0.json)及[演示截图](../home-filter-with-own-0.6.0.jpg)。自己的回复与别人回复自己原帖的区分由逻辑用例覆盖。
- 开启设置时，通知 9/9 布局及 5/5 行高通过。见 [回归结果](../layout-filter-0.6.0.json)。
- 用户手动重载并开启设置后，真实 X“为你推荐”确认 6 张卡片收起：自己的内容 3 条、别人的已完成原帖 3 条。卡片 1px、包含 X 原生边框的 cell 2px；当前 17 个虚拟行按位置排序，相邻间隙最小/最大均为 0px，首张保留帖子紧接隐藏项补位。见 [真实测量](../home-filter-live-0.6.0.json)及[页面截图](../home-filter-live-0.6.0.jpg)。
- 另开真实主页滚动检查了后续加载，未见插件报错或原高度空白。原用户标签检查开始时有非空草稿，未代为修改、关闭或发送；待用户正常操作返回主页后只读测量。以上是当前页面样本，不保证 X 后续排序、媒体加载或站点更新始终无位置变化。
