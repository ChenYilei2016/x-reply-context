# 0.7.0：通知页独立完成项筛选

通知标题栏新增“隐藏已回且已点”切换按钮，默认关闭，开启高亮；再次点击恢复当前已加载的评论。它与主页筛选独立，在当前 Chrome 保存设置，所有通知子页共用。

## 口径与边界

- 仅 `article[data-testid="tweet"]` 评论通知参与筛选，已有分类必须同时确认文字回复与红心。沿用同一原帖、同一个人的标签口径，红心可来自该人在同一对话中的另一条帖子。
- 点赞、关注等聚合通知，以及只完成一项、待确认、自身或普通原帖卡片保留。不删除通知或互动记录，不产生新互动请求。
- 打开回复框、草稿确认等弹窗时暂停折叠与恢复；关闭后应用新记录。新消息与重绘继续分类，连续回复不选择已隐藏项。
- 使用现有通知标题栏设置入口旁的空间，不新增横幅；找不到入口时不隐藏，避免出现无法关闭的筛选状态。保存失败保留旧设置，按钮提示重试。

## 实现与复用

主页已验证的卡片折叠、缓存、分批和过期结果校验抽到 `card-filter.js`，两处各自提供入口、标记与判断条件。主页规则不变；设置键分别为 `hideCompletedHome` 和 `hideCompletedNotifications`，不迁移互动缓存，不新增权限。每批最多 100 张已加载卡片，只调用本地分类。
