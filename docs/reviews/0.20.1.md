# 0.20.1 定时运行标记与跨刷新复核

## 行为与边界

默认随机间隔5～15秒，最低5秒；已有自定义设置保留。次数和总时长仍是同一轮的总预算，不因自动换批重置。页面固定标记独立于回复框，显示运行、等待、刷新衔接和停止，以及次数、截止时间和停止按钮；状态改变才更新文字，不按秒轮询。

仅插件主动执行的自动换批允许续接。旧页在登记后再次核对账号、页面、设置、前台状态及运行是否仍有效，再同步提交导航；新页仅接受前台、同账号、同设置、未过期且有剩余预算的一次性记录。记录只包含运行标识、次数、期限、配置及最后目标ID，不含草稿、Key。手动刷新、历史返回、提前取消、后台或设置变化不恢复旧轮；恢复后重新随机等待至少5秒，不补发错过的间隔。

手动停止会取消本条尚未执行的后续点赞/下一条，并停止AI生成或继续填入，保留已有草稿；已发出的评论不能撤回，成功回执仍保存。达到次数上限允许已触发的本条按原约定收尾，但不会再触发新的评论。

## 子 agent 审阅及修复

独立子 agent 只读审阅了调度、换批、内容脚本、后台和异常保护的调用链，并进行了第二轮复核：

- 修复手动停止仅清计时器、发送回执到达后仍可能点赞的问题，复用现有后续操作取消机制。
- 用专用恢复入口继承次数及原截止时间，禁止通过重新开始来恢复预算。
- 固定标记不随回复框销毁，运行或等待续接时停止按钮不因当前页面未就绪而禁用。
- 修复ARM等待时停止、TAKE尚未返回时手动操作/失焦/配置变化等取消空档。
- CANCEL按换批编号匹配，不删除新票；已消费后仍通过本地扩展消息通知当前页。接收取消只本地停止，不反向发送CANCEL，防止消息回环。
- 区分续接打开回复框与手动打开，避免start/finish提前取消待恢复任务。

子 agent 第二轮未发现新的确定P1/P2问题；独立执行定时与换批专项测试27/27通过。手动停止同时暂停AI的最后接线也经只读复核，未发现回调循环或草稿丢失问题。
