# 0.15.11 快捷回复词义校正

「哈哈／嘿嘿」是普通回应，不等于被逗到、觉得内容好笑或笑出声。移除这类扩展；其余三组也限定为用户原句及少量语气词，不增加新的情境、评价或情绪强度。
