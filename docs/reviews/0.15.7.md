# 0.15.7 回复框快捷填入

通知、为你推荐、正在关注共用回复工具栏，新增固定一行的四个快捷按钮：

| 按钮 | 随机词句 |
| --- | --- |
| 一起加油 | 一起加油好兄弟 / 一起加油鸭 / 一起加油🦆 |
| 哈哈 | 哈哈 / 嘿嘿 |
| 难受啊 | 难受啊 / 难顶呀 / 太难了 |
| 太卷了 | 太卷了 / 别卷了 / 卷不动了 |

每次点击独立随机选择词句和结尾标点 `...`、`!`、`!!!`、`!!`。默认追加到草稿末尾，有文字时用空格分隔，不替换选中的原稿。填入后由用户检查并手动发送。

## 编辑与性能边界

- 只在点击时做两次本地随机选择，通过浏览器原生 `insertText` 编辑路径填入；不直接替换受控编辑器 DOM、不模拟网络发送。编辑命令失败会提示并保留原稿，不自动重试。
- 中文输入法组字、现有改写/填入状态、发送中、结果未确认以及多条帖子编辑时禁用快捷按钮。不会代为点赞、跳过或下一条。
- 固定一行高度，窄屏可横向滚动；不根据抽中的短语改变按钮文字或位置。沿用逐帧刷新，无新增接口请求、计时器、持久化数据或扩展权限。
- 顺带修正首次识别账号时清理标签的范围，只清理列表卡片标签，避免刷新后立即打开回复框时误删底栏标签。

## 验证

74 项 Node 回归通过。Chrome 本地虚构编辑器验证了四组词句、四种标点、草稿选中后仍追加、原生输入事件、输入法保护、命令失败与零发送/零点赞，并验证快捷行及背景卡片位置不变；见[浏览器证据](quick-replies-0.15.7.json)。测试不连接真实 X 账号。
