# 0.16.0 · 真实回复框有限验收

用户已配置自己的模型 API、停用原 XReply。使用独立 Chrome X 通知标签页检查；没有读取 API Key 或模型配置，没有点击发送、点赞或关注。

## 已通过

- 打开空回复弹窗出现真实模型候选；编辑器仍为空，预览没有提前写入草稿。
- 向下键切换成另一条候选，草稿保持为空。
- Tab 逐字采用一次；过程中连续发送与跳过置灰，结束后恢复。
- Option+Tab 开始改写后，立即追加检查文字。返回结果没有覆盖追加内容，并显示“草稿已变化，保留你的新内容；本次改写未应用”。
- 清空本次检查生成和输入的全部文字，再点击“跳过”：进入当前页另一条通知，回复对象及灰字候选更新，编辑器仍为空，没有串入旧草稿。
- 关闭空回复框后编辑器与 AI 预览均清除，独立检查页已关闭。

没有操作用户原有草稿。用户原通知页最初仍提示扩展连接失效，刷新后恢复；随后为避开同时操作，检查移至独立标签页。

## 边界

- 未发送，因此不把“真实发送成功后自动下一条”标为已验收；该路径仍以受控测试为依据。
- 仅确认用户当前配置的一次生成与改写，不代表所有端点或 Prompt 均兼容。
- 关闭前后列表首条因新数据／虚拟列表变化不是同一张卡，不能用两次首条坐标证明滚动位置不变；本次不作全局滚动或大数据性能结论。
- 真实截图和详细记录留在本机私有 artifacts，不放入公开安装包或仓库，避免将账号及通知内容当成公开演示素材。

同时加入黑底白色 X 静态图标（16、32、48、128），源码、安装包与原安装目录 25 个文件逐字节一致。图标须再次重载扩展后由 Chrome 更新；版本为 0.16.0。此记录形成于本次 Git 提交之前。
