# 0.9.0 通知回复框互动信息

## 行为

通知列表通过原生评论按钮进入回复框后，操作区上方增加一行原帖归属、文字/红心依据、我评他 / 他评我、原帖链接和 NEW，复用列表同一渲染函数及已有统计口径。主页连续回复的操作区保持原有行为。

「他的主页 ↗」打开当前评论作者的主页，使用新标签页保留当前草稿；不能使用原帖作者来代替楼中楼的当前回复对象。CLASSIFY 增加 authorHandle，只读取本地已存作者，不新增抓取接口。

## 使用体验与异常

- 信息区域固定 30px，标签过长横向滚动，主页入口保留。加载、读取失败、次数、NEW 和红心状态变化不改变信息行高度。
- 本地记录更新使当前回复框重新查询；普通输入不会重复查询。慢响应通过账号、会话、当前对象及数据修订号核对，避免快速跳过后串人。
- 缓存仅属于本轮当前对象。底栏被 X 重绘时恢复当前信息；旧弹窗关闭后不把结果写进新弹窗。
- 未确认作者时主页入口不可用，统计仍可显示；读取失败保留占位和已有同对象信息，正常回复、跳过及关闭不依赖这次查询。
- 不修改通知隐藏规则、不主动滚动或发送内容、不因打开主页记为已互动。
