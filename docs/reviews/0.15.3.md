# 0.15.3 独立转发通知过滤开关

扩展弹窗新增「通知自动隐藏转发消息」，默认关闭并保存选择。开启后，在接收通知响应时过滤retweet_icon类型的单人/多人转发事件；带正文的引用帖（TimelineTweet）、评论和未知事件保留。与点赞、关注及已完成互动开关独立。

复用已有GraphQL/REST、fetch/XHR过滤入口与分页状态，不新增请求、DOM扫描或隐藏占位。整批过滤后仍暂停历史分页，手动继续只放行一批；设置修改只影响后续响应，已有列表可手动刷新应用。关闭后也需手动刷新才能恢复之前被接收过滤的内容，不自动刷新或取消真实转发。

62项Node检查通过：默认关闭、独立保存、保存失败回滚、单人/多人样例、正文引用保留、旧REST结构、fetch/XHR空批暂停与关闭开关后释放等待。弹窗本地预览已确认开关和提示可正常显示，见[截图](repost-toggle-0.15.3.png)。

用户当前没有新的转发通知，已有历史响应中也只找到点赞/关注事件，未用真实转发响应现场验收。本次事件类型匹配依据既有retweet_icon约定和本地构造样例；未知类型始终保留，不靠文本猜测。没有为了找样本反复翻页或触发真实账号互动。

源码、README、0.15.3安装包及原安装目录已同步。重新加载扩展后，在弹窗启用新开关并刷新X即可应用；本次发布包含源码、README、安装包和验证记录；无关promo目录保持不动。

发布前补充：用户提供仍有两条转发事件的真实现场，随后确认尚未开启独立转发开关。默认关闭时保留这些通知符合预期；该现场不能作为开启后漏滤的证据，真实类型命中仍待启用并刷新后确认。
