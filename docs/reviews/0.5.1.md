# 0.5.1：回复框内的独立手动红心

通知与“主页 → 为你推荐”的回复框，在“跳过 / 发送并下一条”旁增加“♡ 点赞 / ♥ 已点”。每次由用户单独点击，再次点击取消。发送、跳过、打开下一条均不触发点赞。

## 实现与记录

- 根据本轮回复的帖子 ID，重新查找来源卡片内的原生 `like / unlike` 控件，排除嵌套卡片；来源卡片已移出或控件不可用时禁用，不借用其他帖的红心。
- 按钮直接触发 X 原生控件，不新增请求接口或权限。点赞与取消仍由现有观察器读取 `FavoriteTweet / UnfavoriteTweet` 的成功回执，经统一 `OBSERVED → INGEST → chrome.storage.local` 流程保存。
- 原生控件可能先乐观更新，按钮随其状态变化与失败回滚；“已点”不等于插件已确认保存成功。失败响应不创建成功记录，取消成功撤销该条依据。
- 当前帖的按钮与同帖同人的通知汇总标签含义不同：后者可以引用对话中另一条帖的点赞依据，前者只操作眼前正在回复的那条帖子。
- 点赞不增加“我评他 / 他评我”，不改变文字已回状态。状态切换只刷新按钮，不重建背景列表。
- 窄屏工具栏允许说明换行，三个操作按钮保留在同一组。
