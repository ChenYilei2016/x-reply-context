# 0.10.0 正在关注连续回复与通知按钮优化

## 行为与范围

主页的「为你推荐」「正在关注」共用原有手动点赞、跳过和发送并下一条流程。回复框状态标明来源页签；仍只处理当前已加载卡片，不自动翻页或补抓。自己的帖子、已评论原帖、本轮已处理项沿用既有排除规则。

入口判断与主页隐藏判断分开：本次仅扩展连续回复，主页隐藏开关仍只作用于「为你推荐」。自定义页签不启动连续回复；使用页签顺序识别主页前两项，不依赖中文标签。

## 页签隔离与保存

- 启动时记录当前页签索引，弹窗打开后 X 暂时取消页签选中状态，不会使会话丢失。
- 点击另一页签即结束本轮；异步候选返回前再次核对账号、路由和页签，不在另一列表续开回复框。
- 回复保存仍由已有 CreateTweet / CreateNoteTweet 成功回执触发，点赞仍走 FavoriteTweet / UnfavoriteTweet。没有新增点击即记已回或另一条统计路径。
- 已经发出的请求即使之后切换页签，成功回执仍由统一观察链保存；停止的是连续操作，不丢弃真实发送记录。

## 通知按钮显示

右侧「应用更新」改名为「整理列表」。隐藏开关和整理操作改为两个独立圆角按钮，间隔 8px，宽度分别固定为 112px 和 80px；整体仍在固定容器内，标题行高度保持 30px。无内容可整理时仅置灰，不隐藏或改变文字、宽度。只手动应用已加载通知的最新状态，不刷新网页或额外拉取通知。

回复框打开、保存和整理过程中仍禁用操作，原有空回复框、滚动、新通知进入和虚拟列表稳定性策略保留。

390px 窄屏检查：控件宽 200px、高 30px，文档宽仍为 390px，没有横向溢出。截图见 [独立按钮](notification-buttons-0.10.0.jpg)，检查后已恢复默认视口。
