# 0.17.1 · 伴随窗口直接换人

按用户新口径调整 0.17.0 的“存活窗口一律不导航”：点击另一个人的伴随主页时，直接导航原窗口中的托管标签；同一个人只聚焦，不重复加载。

## 范围

- 不检查右侧草稿、AI、发送或编辑状态，不替用户保存或发送。右侧原生 X 若弹出离开页面确认，仍由用户处理。
- 左侧只发送打开目标请求，不调用来源页导航、滚动、草稿写入或原生关闭按钮。
- 后台只保留一个正在执行的操作和一个最新待处理目标，快速点击不产生无界队列或多个窗口。所有操作由点击触发，不轮询、不预取、不自动重试。
- 保存托管标签 ID；标签被移出伴随窗口时不误导航别的标签。兼容 0.17.0 单标签窗口尚未记录 tabId 的情况。
- 导航前将目标标为未确认，成功后再更新；失败不会把没打开的人当成已打开，也不会自动重试。
- Chrome 会话引用、关闭清理及约 800px 窗口尺寸沿用 0.17.0。重载扩展前先关闭原伴随窗口。

## 验证

- Node 测试 **111/111**，含 11 项伴随窗口检查：快速多目标最终落到最新对象；同人及大小写变化不重新导航；换人保持原窗口、原标签；工作线程恢复；关闭重建；存储／聚焦／导航失败；旧记录兼容；托管标签移走不误操作。
- 本次没有在真实 X 发送、点赞，也没有触发 AI。
- 0.17.0 的真实通知非空草稿与 77 张卡片位置验证保留在原报告；本版导航修改通过模拟 Chrome API 验证，**不能当作 0.17.1 的真实换人验收**。
- README 同步新版展示布局、点赞发送流程图及 0.17.1 伴随窗口示意图；图片链接存在，SVG XML 结构校验通过。

源码、安装包与原安装目录同步为 0.17.1，重载并刷新 X 后生效。
