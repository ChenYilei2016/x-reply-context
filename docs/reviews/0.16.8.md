# 0.16.8 · 移除双向关注展示

按用户最新要求，移除回复框中的「我关注他／他关注我」。同时删除该功能专用的页面缓存、字段提取回调、FOLLOW_CONTEXT 页面消息、首次账号初始化读取及对应脚本入口，避免留下无用途的数据采集和运行开销。

保留评论／点赞历史、双向评论次数、NEW、原帖摘要与主页入口。通知中的「关注了你」消息过滤和主页「正在关注」入口属于不同功能，保持原样。没有清除或迁移用户存储。

## 本次提交范围

- 包含 0.16.7 的「点赞发送下条」组合和原来同一行紧凑布局。
- 当前代码不再运行 0.16.5／0.16.6 的双向关注与初始化读取方案。
- 0.16.6、0.16.7 的安装包和验证记录保留为历史；当前应安装 0.16.8。移除源码的本机副本另存于 artifacts，未保留为运行依赖。

## 验证

- 剩余自动测试 **93/93**；被移除功能的 18 项专用测试一并撤下，评论、点赞、过滤、存储、AI 与组合操作相关测试保留。
- 生产代码及当前测试中不再有双向关注模块、初始化读取模块、FOLLOW_CONTEXT 或对应 DOM 类的引用。
- 本地回复框只读检查：关注行数量为 0，无对应文案，原互动标签、原帖摘要和「点赞发送下条」仍存在。
- 0.16.7 的组合操作受控检查结果保留，见 [记录](0.16.7.md)。本轮未在真实 X 发布评论或点赞；新版真实 UI 需重载后确认。
