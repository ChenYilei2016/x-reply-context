# 0.17.4 · 标签搜索回复入口

## 原因与修复

只读核对用户真实页面：从帖子中的 `#浇朋友` 进入后，地址是 `/hashtag/%E6%B5%87%E6%9C%8B%E5%8F%8B?src=hashtag_click`，热门／最新页签也使用 `/hashtag/浇朋友`，而不是 `/search?q=…`。原搜索入口只接受后者，因此未启动插件会话。

在原搜索 URL 标准化函数中，将有效标签路径转换为相同的 `q=#标签` 标识，兼容中文原文与百分号编码。仍保留 `f` 页签和其他筛选参数，只忽略 `src` 来源参数。会话校验同时接受 `/search` 与 `/hashtag/…`，回复弹窗切换到 `/compose/post` 后继续核对背景页签链接。

换标签、换页签、换筛选会结束旧会话；不支持的用户／媒体／列表页签保持不启动。没有新增 X 请求、DOM 观察器、数据存储或分页，工具栏、双向互动数和回执保存均复用原实现。
