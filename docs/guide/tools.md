# 关注列表筛选与视频下载

[← 返回 README](../../README.md)

## 关注列表筛选

在个人主页的「认证关注者／你认识的关注者／关注者／正在关注」列表顶部，组合使用三个条件：

- **粉丝数 <**：只保留粉丝数低于上限的账号，留空不限。
- **关粉差 ≤**：关注数不少于粉丝数时直接通过。只有粉丝更多时，才用「(粉丝数 − 关注数) ÷ 粉丝数」算差距。例如粉丝 8,000、关注 6,000，差距为 25%。
- **隐藏已关注**：根据 X 原生按钮状态，过滤你已经关注的人。

「应用」只处理当前已加载的账号，翻页后可再应用；「清除」恢复显示。缺少数据时不按该项排除。筛选复用页面已有数据，不额外请求 X 或自动关注。

点击「应用」会把条件按当前登录账号保存在本机。刷新后自动填回，再点「应用」即可筛选。「清除」也会清掉已保存的条件。

## 帖子视频下载

打开「回过了」弹窗，在「帖子视频下载」粘贴 X 或 Twitter 的帖子链接。当前在帖子详情页时会自动填入链接。点「下载 MP4」，Chrome 会保存为 `X-帖子ID.mp4`。

优先复用当前标签已加载的视频，必要时在临时标签正常打开一次原帖。多段视频时下载第一段可用视频的最高码率 MP4。引用帖中的视频请使用视频原帖的链接。
