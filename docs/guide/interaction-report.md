## 互动分析

在已登录的 X 标签页点击扩展图标，再选 **互动分析 ↗**。报表按当前账号查看本机记录，每页显示 50 位作者。

- 想找可能漏回访的人，点「仅他评我有记录」，再设定「他评我最少」篇数。点「他评我较多」也能看双方已有记录但他评论得更多的人。
- 想看自己常去评论的作者，点「仅我评他有记录」或「我评他较多」，再按「我评他」排序。两列可独立设置最低篇数，也能搜索用户名或账号 ID。
- 点「标记跳过」可加入扩展的本地跳过名单。「已标记跳过」里可以恢复。统计沿用不同原帖去重的口径，「待确认」表示本机缺少这一方向的记录。
- 点「加入白名单」可让作者免受「为你推荐」的互动差值过滤。「白名单」筛选里可以移除，名单按 X 账号 ID 保存在本机。
