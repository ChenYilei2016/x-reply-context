# 创作工作台

[← 返回 README](../../README.md)

## 写作台：角度与成稿（0.29.0）

在选题雷达里选入 1～3 条素材，点底部「去写作台 →」（也可从扩展弹窗进入）。

1. **找角度**：模型返回 3～5 个结构化角度，每个包含类型（解读、反常识、清单、教程、吐槽、预测、对比、故事）、开头钩子、提纲、依据的素材编号和风险提示。
   - 写作台会把同话题里有浏览数据的 X 帖子（最多 8 条）一起发给模型对照：已经有人用这个角度写过的标为 **已有人写**，并附上参考帖；其余标为 **新角度**。
   - **潜力只看真实数据**：已有人写的角度显示同角度参考帖的最高浏览和流速；没有参考帖时显示“无依据”，不给打分。模型引用不存在的素材或参考帖编号时直接丢弃。
   - 素材只有标题、发布超过 48 小时时，素材区会提前提示。
2. **成稿**：在角度卡片上点「用这个写」，或不选角度直接生成。一次出 **3 个候选**，开头手法各不相同。
   - 形态：**中短帖观点**（约 150～400 字）或 **引用转发**（约 50～150 字，复制时在末尾附上原帖链接，X 会显示为引用）。
   - 可以填写本次附加要求，例如“结尾抛一个问题”。
3. **编辑**：切换候选后直接修改，每个候选的修改分别保留，可「还原本候选」。
   - **加权字数**按 X 的规则计算：中日韩文字和 emoji 计 2，链接计 23，显示 Premium 上限 25,000。
   - **首屏标线**：超过 280 加权字符（约 140 个汉字）时，时间线会折叠成“显示更多”。预览里用红线标出折叠位置，钩子要放在线前面。
   - 「去 X 发布」：保存为“待确认”草稿，复制正文，并在新标签页打开预填好正文的 X 发帖页，仍由你在 X 上点发布。正文太长不能预填时只打开发帖页，粘贴即可。
   - 「保存草稿」存进「草稿与复盘」；「复制」只复制正文。用过的素材在雷达里标为“已写过”。
4. **人设与样本**：人设可以直接编辑，默认是“小娱乐、大 AI 科技”的通用定位，不含个人信息。样本最多 5 条：手动粘贴的排在前面（每条之间单独一行写 `---`），再按浏览量补近 60 天自己的帖子（bot feed 中标记 `own: true` 的条目），不想用的可以排除。样本只用来学习语气和排版。
5. **每一步单独选模型**：在「AI 设置 → 创作工作台模型」里分别给「找角度」和「成稿」指定 API 配置，不指定时跟随当前配置。创作功能不需要打开「开启 AI API」，模型域名首次使用时在写作台点「授权模型域名」。

关闭页面后再打开，素材、角度、候选和编辑内容都会恢复。换了素材后，旧角度会提示需要重新找。模型请求最多等待 90 秒，可以取消。

## 草稿与复盘（0.30.0）

写作台左侧或扩展弹窗 → **草稿与复盘**。

- **状态**：草稿 → 待确认（已打开 X 发帖页）→ 已发。草稿和待确认的可以直接改正文、去 X 发布、复制或删除；已发的正文以 X 上为准，不再修改。
- **自动关联已发帖子**：扩展不读取 X 页面。你的 bot 在 feed 里带回自己的帖子（`own: true`）后，打开本页或点「检查已发」时，按正文自动匹配回草稿并标为已发。匹配会忽略链接（X 会改成 t.co）、空白和标点，发帖前小改几个字也能对上；只匹配草稿创建之后、最后修改后 14 天内的帖子。
- **手动关联**：点「标记已发」，粘贴帖子链接（x.com 或 twitter.com 均可）。关联错了可以「撤销关联」。
- **数据**：优先用 bot 汇报的浏览、点赞、转发、评论；没有时可以手动录入。还会显示**发布后 24 小时内**最后一次读到的浏览量（来自 bot 的多次汇报）。帖子素材 90 天后会从素材库清理，草稿里保留最后一次读数。
- **复盘**：统计已发篇数、有数据的篇数、平均浏览，并按角度类型和帖子形态分别列出篇数、平均浏览、平均点赞和最高浏览。没有数据的帖子计入篇数，不计入平均。
- **反哺样本**：已发且有浏览数据的帖子自动成为写作台的爆款样本候选，和 bot 带回的自己的帖子一起按浏览量挑选。
- 最多保留 500 份草稿，超出时从最久未改的未发草稿开始删除，已发的不删。
- 0.26.0 旧版写作面板的草稿在升级时自动迁入，标为「旧版迁移」；旧面板及其新闻缓存已删除。

## 选题雷达（0.28.0）

点击扩展图标 → **创作工作台 · 选题雷达**。

- **话题合并**：同一事件在不同渠道出现时（例如百度热搜、IT之家和几条 X 帖子都在讲同一件事）合并为一个话题，显示「N 个来源」。中文按双字、英文和型号按词匹配；只与话题锚点比较，48 小时以外不合并。阈值用真实素材校准，宁可少合并，不误合并。
- **综合排序**：先在每个渠道内部按热度排名（有流速看流速，热榜看名次，新闻看新鲜度），再按「渠道内排名 + 跨渠道印证 + 爆文倍数 + 新鲜度」打分，并按账号定位加权：AI 1.0、科技 0.9、产品与开源 0.85、热点 0.7、娱乐 0.6。不同平台的数字不直接比较。
- **其他排序**：流速（每小时平均浏览）、爆文倍数（浏览 ÷ 作者粉丝）、来源数、最新。
- **筛选**：分类标签、素材类型（含 X 帖子／文章／热榜）、24／48／72 小时、关键词（标题、正文、作者）。单次最多读入 3000 条素材。
- **话题操作**：收藏、隐藏（可在「已隐藏」恢复）。点标题打开详情，查看每条素材的来源、作者粉丝、浏览、互动和指标可信度。
- **选材栏**：最多选 3 条素材，点「去写作台 →」生成角度和成稿，也可「复制为素材文本」粘贴给其他工具。写过的话题显示“已写过”。

## 素材渠道（0.27.0 起）

> 0.28.1 起不再从 X 页面抓取帖子（原「X 浏览采集」和帖子流速标签已下线），X 相关素材统一通过「我的 bot」等自有或官方渠道接入；升级时会自动清除此前采集的数据。

点击扩展图标 → **素材渠道 · 授权与状态**。所有渠道都转换成同一种素材结构，存入本机素材库（IndexedDB），供选题雷达使用。

1. 首次点「授权全部渠道」，允许扩展读取各渠道的主机。也可以逐个授权，或关闭不需要的渠道。
2. 浏览器开着时，后台每 5 分钟检查一次，到期的渠道自动拉取；也可以点「立即刷新全部」或单个渠道的「刷新」。
3. 某个渠道失败时，按 15 → 30 → 60 分钟退避重试，其他渠道照常工作。每个渠道显示最近成功时间、本次条数、新增条数和错误原因。

| 分类 | 渠道 | 周期 | 带的数据 |
| --- | --- | --- | --- |
| X 情报 | **我的 bot** | 15 分钟 | 按 [bot 接入约定](bot-feed.md) 输出的任何内容，例如 Grok 搜到的 X 爆帖 |
| AI | OpenAI News、Google AI、量子位 | 30～60 分钟 | 标题、摘要、发布时间 |
| 科技 | IT之家 | 30 分钟 | 正文（按关键词自动识别 AI 内容） |
| 开源 / 科技 | Hacker News、GitHub Trending | 30～120 分钟 | HN 分数与评论数；仓库星标与今日增长 |
| 产品 | Product Hunt | 60 分钟 | 产品一句话介绍 |
| 热点 / 娱乐 | 百度热搜、B站热门 | 30 分钟 | 热搜名次；B站播放、点赞、收藏与发布时间 |

**指标可信度**：渠道报告（如 bot、B站汇报的数字）> 仅名次（如热搜）。同一条内容被多个渠道带来时，自动合并，保留更完整的正文和更可信的指标。

**保留策略**：素材 7 天内没有再出现就清理；X 帖子 48 小时后浏览仍不足 1000 的先清理；收藏的不清理；feed 标记为自己的帖子保留 90 天；总量上限 2 万条。

微博、知乎、抖音热榜需要登录或签名，没有直接接入，可以交给 bot 抓取后写进 feed。
