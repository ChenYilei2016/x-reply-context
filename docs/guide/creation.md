## 创作工作台

点击扩展图标 → **创作工作台 · 自动新闻素材**，无需先打开 X。

- 首次点击「授权并加载素材」，允许读取 IT之家、少数派和 Google AI。之后打开工作台会检查更新，15 分钟内优先复用缓存；刷新失败保留旧素材并显示来源错误。每源最多保留 30 篇。
- 按来源、关键词、未使用／已使用、已有正文筛选，支持收藏与隐藏。RSS 是新闻来源，不代表已成为爆文；X 爆文 API 尚未接入。
- 选择 1～3 篇素材，可以单篇改写或多篇融合；选择风格、字数，填写附加要求。只有摘要的来源会尝试补正文，读取失败时明确按摘要生成；事实不足时不生成。
- 「找写作角度」给出基于所选素材的建议，可一键带入要求生成成稿，不宣称全网无人写过。结果先单独展示，点击「采用为草稿」才替换编辑区。
- 创作沿用 AI 设置中当前 API 配置，有独立人设与提示词，不要求开启 AI 评论。缺少模型域名权限时可在工作台授权。模型请求最多等待 60 秒，可以取消。
- 草稿自动在本机保存，最多 50 份。刷新后恢复最近草稿；多窗口打开同一草稿时，旧版本不能覆盖新版本，可「另存一份」。复制正文后到 X 核对发布，也可手动标记素材已用。草稿和来源缓存尚不包含在互动记录备份中。

来源原文和链接供核对事实。素材中的图片、视频不会作为生成输入，也不会自动转载。浏览器关闭时不采集；重新打开后只能补拉来源仍提供的条目。首版没有后台服务器或新闻订阅费用，模型请求按自己的 API 计费。
