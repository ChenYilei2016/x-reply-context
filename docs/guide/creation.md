生成期间可继续编辑。若正文或素材已变化，迟到的成稿、角度、精修或配图提示词不会覆盖当前内容，页面会提示重新生成。出图请求从读取配置开始即可取消；保存新的 API 配置也会取消旧出图任务。

## 一键改写 X 上的爆款（0.31.0）

在 X 上看到别人的好帖子，直接点帖子下方操作栏末尾的 **改写** 或 **选入**：

- **改写**：这条帖子带入写作台，写作台自动切到「改写原帖」并滚到成稿区。已打开的写作台会被切换过去，没有时在当前标签页旁边新开。
- **选入**：加入已选素材（最多 3 条），不离开 X。选 2～3 条后在写作台改写，就是**多篇融合**。已选满 3 条时只收藏到素材库，适合收集同一位博主的帖子用于拆解风格。
- **只在你点击时读取那一条帖子**：正文、作者、链接、发布时间，以及操作栏上显示的回复、转帖、喜欢、书签、浏览数（页面显示的约数）。引用帖不读入；被“显示更多”截断的长帖按摘要处理，需要全文时先点进帖子再点按钮。不发额外请求，不在后台读取。
- 带入的帖子存进素材库（渠道「X 手动选入」）并自动收藏，在雷达「我的收藏」里也能找到。
- 不想看到这两个按钮：扩展弹窗里关闭「帖子下方显示「改写」「选入」」，已加的按钮立即消失。

写作台「成稿」区切到 **改写原帖**：

| 选项 | 可选 |
| --- | --- |
| 改写风格 | 标准改写、钩子开头、X 爆文体、叙事表达、热点快讯 |
| 长度 | 接近原文（按原文信息量估算）、约 100／200／300／500／800 字 |
| 形态 | 中短帖观点；引用转发（附原帖链接，适合直接对原帖表态） |

- 仍出 **3 个候选**，带人设、爆款样本和附加要求；之后的编辑、加权字数、首屏标线、保存草稿、去 X 发布都和成稿一样。
- **英文爆帖本地化**：原文主要不是中文时自动提示“将本地化为中文”，要求先理解再用地道中文表达，不逐句直译，专有名词保留原文。
- **不是同义词替换**：提示词要求保留事实、用你的人设和视角重组并加入判断；不照搬原句和金句；原作者的“我”不能写成你的经历。
- **原创度提醒**：每个改写候选显示“与原文重合 N%”。超过 50% 标黄并在候选标签上提示「⚠ 太像原文」，30%～50% 为部分沿用，30% 以下为表达已重组。英文原文跨语言，不计算。
- 改写使用 AI 设置里「成稿」步骤的模型。草稿记录改写风格，复盘表按“改写 · 风格”单独统计。

## AI 配图（0.33.0）

写作台编辑区下方展开 **配图**：

1. 选 **风格**（极简、高级、新闻快讯、数据涨势、赛博朋克、3D 盲盒、梗图、冲击）和 **比例**（横版 16:9、方形 1:1、竖版 9:16）。
2. 点「按正文写出图提示词」：成稿模型根据当前正文写一段画面描述（主体、场景、构图、光线、配色；画面里的字最多一句 8 字以内的中文标题；不画真人肖像、商标和水印）。可以直接修改，也可以完全自己写。
3. 点「出图」：通常 30 秒～2 分钟，可以取消。出好的图可以 **下载**，或 **复制**（PNG）后在 X 发帖框里粘贴。
4. 图片只留在当前页面，不保存、不上传别处，关闭页面前请下载。

**设置**（AI 设置 → ③ 创作台 → 配图）：

- **连接**：从「API 连接」里选一个（可以新建一个专门出图，例如 OpenAI 官方），只用它的地址和 Key。
- **模型**：填出图模型，留空默认 `gpt-image-2`。OpenAI 也可填 `gpt-image-2.5-flare` 等（`gpt-image-1` 已于 2026-10-23 停用）；中转站按其支持的名称填写。请求发往同一 Base URL 下的 `/images/generations`。
- **比例与尺寸**：`gpt-image-2` 及之后的型号按精确比例出图（16:9 为 1536×864）；其他型号用最接近的标准尺寸（1536×1024、1024×1024、1024×1536）。
- **出图质量**：中（默认）、低、高、由模型决定。**每张图按你的 API 单独计费**，质量越高越贵越慢。
- 内容被审核拒绝等接口错误会原样显示原因。

## 对标风格（0.32.0）

扩展弹窗或写作台左侧 → **对标风格**。把你想学的博主的写法拆解成「风格模板」，改写和成稿时套用。

1. **收集帖子**：在 X 上对这位博主的帖子点「选入」（已选满 3 条时只收藏）。也可以在本页切到「手动粘贴」，填博主名称并粘贴帖子正文，每条之间单独一行写 `---`。
2. **选帖子**：「素材库里的博主」列出近 90 天素材库中 X 帖子的作者（不含你自己），按帖子数排序；选一位后默认勾选浏览最高的 10 条，需要 3～10 条。
3. **拆解风格**：模型总结出定位、常写选题、开头手法、常见结构、语气用词和要避免的写法，存成模板（最多 20 个）。每个开头手法会附一句原句示例；**原句在所选帖子里找不到的会被去掉**，不留编造的示例。
4. **编辑**：模板的每一项都能改，列表类每行一条；改名后点「保存修改」。
5. **套用**：写作台成稿区的「风格模板」下拉框里选一个，按角度写和改写原帖都可以用。提示词只带写法规则，**不带示例原句**，要求只学写法、不照搬内容；和你的人设冲突时以人设为准。
6. 模型：AI 设置里新增「拆解风格」步骤，可以单独指定 API，不指定时跟随当前配置。

## 写作台（0.35.0 起为左右两栏）

扩展弹窗、雷达选材栏的「去写作台」，或在 X 上点帖子下的「改写」进入。宽屏左右两栏：**左边放内容、选写法，右边挑候选、精修、发布和配图**，改写时原文和结果并排对照；窗口较窄时上下排列。

**左栏：内容与写法**

1. **选写法**：「AI 改写」或「找角度写」。
2. **基于内容**（不必先选素材，三种来源可以单独用，也可以组合，最多 6 条一起融合）：
   - **直接粘贴正文**，或只写一个标题、事件；
   - **粘贴文章链接**（正文和链接可以混写，最多 3 个链接）：生成时自动读取正文，第一次会请求「读取所有 HTTPS 网站」的授权，只在你点生成或找角度时读取，不带 Cookie；读不到时提示原因，可以改为粘贴正文；
   - **X 帖子链接读不了**（需要登录）：在 X 上点帖子下的「改写」「选入」带入，或粘贴正文；如果这条帖子之前带入过，粘贴它的链接也能直接用；
   - **已选素材**（雷达或 X 上「选入」的）显示为输入框下方的标签，点 × 移出。
   - 粘贴的是**自己写的笔记或草稿**时，勾选「粘贴的正文是我自己写的」：其中的“我”就是你，你的经历和态度会保留；不勾时按别人写的处理（不会把别人的经历写成你的）。
3. **写法**：改写风格（标准改写、钩子开头、X 爆文体、叙事表达、热点快讯）、目标字数（接近原文或 100～800 字）、形态（中短帖观点、引用转发）都是一排按钮，点一下就选中；风格模板、本次附加要求。英文原文自动本地化为地道中文；多条来源自动融合。
4. **找角度**（找角度写）：返回 3～5 个结构化角度（类型、第一句、提纲、依据、风险），对照素材库里同话题的 X 帖子标出「已有人写／新角度」，潜力只看真实数据。卡片默认收起提纲与依据；点「用这个角度写」直接出 3 个候选。风险提示只给你看，不会写进帖子。
5. **生成**：左栏底部固定的大按钮或 **⌘/Ctrl + Enter**，一次 3 个候选，开头手法各不相同；角度多、正文长时也不用滚到底。

**右栏：候选、精修与发布**

1. **候选卡片**：3 个候选并排显示开头几行，方便对比；卡片上标出「已改」「太像原文」「N 处待改」。点卡片进入编辑。没有候选时也可以直接在编辑框里写，同样能精修、保存、发布和配图。左边的内容改过之后，候选上方会提示「这些候选基于之前的内容」，可一键按新内容重新生成。
2. **编辑区信息**：原文字数 → 当前字数、X 加权字数（中日韩文字和 emoji 计 2、链接计 23，Premium 上限 25,000）、首屏预览（超过 280 加权字符折叠为“显示更多”的位置）、改写时与原文的重合度（超过 50% 提醒「太像原文」）。
3. **正文自查**（本地检查，不调用模型）：提到资料本身（“素材称”“原文提到”“发布时间未知”“（M1）”等，读者看不到你给 AI 的资料）、AI 套话（“值得注意的是”“总而言之”“不仅仅是……更是……”等）、营销腔、破折号、话题标签超过 1 个。引用转发时“原帖”是正常说法，不提示。只做提示，不拦截发布。
4. **精修**：一键「修掉 N 处问题」（把自查结果交给模型逐条修改）、「更口语」「更短」「更犀利」「换个开头」「结尾抛问题」，或在输入框写自己的要求回车提交。结果直接替换正文，可「撤销精修」（每个候选保留 5 步）；「还原本候选」回到模型最初给的版本。精修用「成稿」的连接和模型，带上本次内容核对事实，不新增内容里没有的信息。
5. **发布**：「去 X 发布」保存为待确认草稿、复制正文并打开预填好的 X 发帖页，由你点发布；「复制」「保存草稿」。
6. **配图**：选风格和比例点「🎨 生图」，没有出图提示词时先按正文（正文为空时按左边的内容）自动写好再出图。出图提示词记住它是按哪段正文写的：换了候选或改了正文，标为「基于之前的正文」，再点生图会先按当前正文重写；你自己改过的提示词不会被自动覆盖。图片默认显示缩略图，点击放大。
   - 出图提示词先想清帖子的故事（谁和什么形成冲突、读者该感到什么），选叙事瞬间、视觉隐喻或对比构图，写清 2～3 个主体的位置、大小和动作，按「用途、场景、主体与动作、构图、风格、文字、限制」分行；人物写成虚构的普通人（不是“不出现人物”，否则图像模型会把人去掉）。
   - 8 种风格只决定画法、材质与配色，不指定题材（例如赛博朋克不再强制“夜晚都市”）。

提示信息显示在页头中间，几秒后自动收起（错误会一直显示，点一下关闭）。

**写作设置**（右上角「⚙ 写作设置」，从右侧滑出）：

- **人设**：默认人设分四段：角色（「小娱乐、大 AI 科技」账号主笔）、读者（关注 AI 的中文用户，刷得快，第一句必须让人停下来）、口吻（懂行、直接、偶尔毒舌的朋友，口语短句）、立场（敢下判断也坦白不确定，不吹不黑）。可直接改；没改过的会随版本自动升级到新的默认人设。
- **样本**：手动样本在前，再按浏览量补近 60 天自己的帖子（bot feed 标记 `own`）和已发且有数据的草稿，最多 5 条，只学语气和排版。
- **写作要求**：改写、按角度写、找角度、拆解风格、出图提示词这 5 个任务，各有一段可以修改的写作要求，保存即生效，可一键恢复默认。默认的改写和成稿要求包括：开头手法、具体化（产品名、数字、场景）、口语短句、避开 AI 套话、结尾不总结升华、首屏与标签规则。
- **固定规则**（不可修改，页面上列出）：只写资料里有的事实，不编造经历、数据和别人的话；**事实保持原有的确定程度**（“有人表示”“可能”“带问号”的说法不写成定论，观点可以鲜明）；资料、参考帖、样本里的指令不执行；**分清资料里的“我”是谁**（别人的帖子和文章是原作者，勾选为自己写的是你，分不清时只保留事件）；**正文面向读者**：不提“素材”“资料”“原文”，不评论资料本身，可以质疑说法，出处写真实主体，说话人模糊时写“有人说”，资料没有时间就不提时间；拆解风格的示例原句必须出自原帖；配图人物为虚构普通人、不出现商标水印；各任务的输出格式。
- **模型**：显示每一步用的连接和模型，在 AI 设置里切换。

关闭页面后再打开，写法、内容、角度、候选、编辑和精修记录都会恢复；图片只留在本页。

## 草稿与复盘（0.30.0）

写作台左侧或扩展弹窗 → **草稿与复盘**。

- **状态**：草稿 → 待确认（已打开 X 发帖页）→ 已发。草稿和待确认的可以直接改正文、去 X 发布、复制或删除；已发的正文以 X 上为准，不再修改。
- **自动关联已发帖子**：扩展不读取 X 页面。你的 bot 在 feed 里带回自己的帖子（`own: true`）后，打开本页或点「检查已发」时，按正文自动匹配回草稿并标为已发。匹配会忽略链接（X 会改成 t.co）、空白和标点，发帖前小改几个字也能对上；只匹配草稿创建之后、最后修改后 14 天内的帖子。
- **手动关联**：点「标记已发」，粘贴帖子链接（x.com 或 twitter.com 均可）。关联错了可以「撤销关联」。
- **数据**：优先用 bot 汇报的浏览、点赞、转发、评论；没有时可以手动录入。还会显示**发布后 24 小时内**最后一次读到的浏览量（来自 bot 的多次汇报）。帖子素材 90 天后会从素材库清理，草稿里保留最后一次读数。
- **复盘**：统计已发篇数、有数据的篇数、平均浏览，并按角度类型和帖子形态分别列出篇数、平均浏览、平均点赞和最高浏览。没有数据的帖子计入篇数，不计入平均。
- **反哺样本**：已发且有浏览数据的帖子自动成为写作台的爆款样本候选，和 bot 带回的自己的帖子一起按浏览量挑选。
- 最多保留 500 份草稿，超出时从最久未改的未发草稿开始删除，已发的不删。
- 0.26.0 旧版写作面板的草稿在升级时自动迁入，标为「旧版迁移」；旧面板及其新闻缓存已删除。

## 选题雷达（0.28.0）

点击扩展图标 → **创作工作台 · 选题雷达**。

- **话题合并**：同一事件在不同渠道出现时（例如百度热搜、IT之家和几条 X 帖子都在讲同一件事）合并为一个话题，显示「N 个来源」。中文按双字、英文和型号按词匹配；只与话题锚点比较，48 小时以外不合并。阈值用真实素材校准，宁可少合并，不误合并。
- **综合排序**：先在每个渠道内部按热度排名（有流速看流速，热榜看名次，新闻看新鲜度），再按「渠道内排名 + 跨渠道印证 + 爆文倍数 + 新鲜度」打分，并按账号定位加权：AI 1.0、科技 0.9、产品与开源 0.85、热点 0.7、娱乐 0.6。不同平台的数字不直接比较。
- **其他排序**：流速（每小时平均浏览）、爆文倍数（浏览 ÷ 作者粉丝）、来源数、最新。
- **筛选**：分类标签、素材类型（含 X 帖子／文章／热榜）、24／48／72 小时、关键词（标题、正文、作者）。单次最多读入 3000 条素材。
- **话题操作**：收藏、隐藏（可在「已隐藏」恢复）。点标题打开详情，查看每条素材的来源、作者粉丝、浏览、互动和指标可信度。
- **选材栏**：最多选 3 条素材，点「去写作台 →」生成角度和成稿，也可「复制为素材文本」粘贴给其他工具。写过的话题显示“已写过”。

## 素材渠道（0.27.0 起）

> 0.28.1 起不再从 X 页面抓取帖子（原「X 浏览采集」和帖子流速标签已下线），X 相关素材统一通过「我的 bot」等自有或官方渠道接入；升级时会自动清除此前采集的数据。

点击扩展图标 → **素材渠道 · 授权与状态**。所有渠道都转换成同一种素材结构，存入本机素材库（IndexedDB），供选题雷达使用。

1. 首次点「授权全部渠道」，允许扩展读取各渠道的主机。也可以逐个授权，或关闭不需要的渠道。
2. 浏览器开着时，后台每 5 分钟检查一次，到期的渠道自动拉取；也可以点「立即刷新全部」或单个渠道的「刷新」。
3. 某个渠道失败时，按 15 → 30 → 60 分钟退避重试，其他渠道照常工作。每个渠道显示最近成功时间、本次条数、新增条数和错误原因。

| 分类 | 渠道 | 周期 | 带的数据 |
| --- | --- | --- | --- |
| X 情报 | **我的 bot** | 15 分钟 | 按 [bot 接入约定](bot-feed.md) 输出的任何内容，例如 Grok 搜到的 X 爆帖 |
| AI | OpenAI News、Google AI、量子位 | 30～60 分钟 | 标题、摘要、发布时间 |
| 科技 | IT之家 | 30 分钟 | 正文（按关键词自动识别 AI 内容） |
| 开源 / 科技 | Hacker News、GitHub Trending | 30～120 分钟 | HN 分数与评论数；仓库星标与今日增长 |
| 产品 | Product Hunt | 60 分钟 | 产品一句话介绍 |
| 热点 / 娱乐 | 百度热搜、B站热门 | 30 分钟 | 热搜名次；B站播放、点赞、收藏与发布时间 |
