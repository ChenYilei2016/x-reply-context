# 改写与对标：设计稿

日期：2026-11-17 · 状态：**已确认**，按第 7 节任务实施 · 前置：[创作工作台 v2 设计稿](2026-11-16-creation-studio.md)（0.27.0～0.30.0 已完成）

## 1. 目标

1. 在 X 上看到别人的爆款、好文时，**一键拿去改写**，改成自己的帖子。
2. 继续对标 [SoPilot](https://sopilot.net/zh) 和 [BlueV](https://bluev.fun)，让写作台的创作和改写更方便。

用户已确认的范围（2026-11-17）：

| 问题 | 决定 |
| --- | --- |
| 改写入口 | 帖子下方加「改写」「选入」按钮，**只在点击时读取那一条帖子** |
| 改写方式 | 风格改写、英文爆帖本地化、多篇融合（引用转发评论沿用现有“引用转发”形态，不单独做） |
| 后续对标 | 对标账号风格、AI 配图（海报、推文串暂不做） |

## 2. 调研结论（2026-11-17）

| 能力 | BlueV | SoPilot | 我们 |
| --- | --- | --- | --- |
| X 页面入口 | 推文下方按钮：选择、改写、海报、视频下载；各按钮可单独关；“仅在点击按钮时读取所选推文” | 帖子页点插件图标 → 下拉选评论／转帖／私信／创作指令，结果回填输入框 | **复刻 BlueV**：帖子下方「改写」「选入」，可在弹窗关闭 |
| 改写 | 粘贴正文或链接；多链接融合；风格 6 种（标题公式、钩子开头、标准改写、叙事表达、热点快讯、X 爆文体）；字数“基于原文”或 50～1000 字；附加要求；一次一稿 | 爆款推文仿写与润色；提示词强调“创造性重构，不生硬复述”；推文改写为推文串；翻译英推 | **超越**：风格 + 字数 + 人设 + 爆款样本，**3 个候选**，原创度提醒（与原文相似度），英文原文自动本地化，首屏标线 |
| 找角度 | 改写页内“找角度”：已有角度候选／新角度 | 热点借势二创 | 已有（0.29.0），并对照同话题 X 帖 |
| 对标 | — | 对标蒸馏：输入账号或领域，拆解定位、选题、钩子，生成可复用规则 | **复刻**：用你选入的某位博主的帖子拆解出“风格模板”，改写和成稿时套用 |
| 配图 | 配图风格 8 种（赛博朋克、3D 盲盒、梗图、冲击、极简、高级、数据涨势、新闻快讯），比例 16:9／9:16／1:1 | 结构化正文配图、文字动画短视频 | **复刻**：同样的风格与比例，用你自己的出图 API |
| 发布 | 直接、定时（OAuth） | 一键分发多平台 | 预填 X 发帖页（0.30.0），不接 OAuth |

不做：自动评论、自动互动（SoPilot 的互动自动化有平台风险）、OAuth 定时发布。

## 3. X 帖子按钮（0.31.0）

- 在时间线、搜索、帖子详情页的每条帖子操作栏末尾加两个小图标按钮：**改写**、**选入**。只装饰尚未处理的帖子；不改变卡片高度；引用帖内部不加。
- 默认开启，扩展弹窗可关闭（`creationPostActions`）。关闭后已加的按钮立即移除。
- **只在点击时读取这一条帖子**的页面内容：正文（被“显示更多”截断时标为摘要）、作者名与账号、帖子链接与编号、发布时间、操作栏上显示的回复／转帖／喜欢／书签／浏览数（按中英文界面解析“1.2万”“250K”等写法，属于页面显示的约数）、是否带图片或视频。不发任何额外请求，不在后台读取。
- 点击后发给后台 `CREATION_PICK_POST`：按统一素材结构写入素材库，渠道为 **「X 手动选入」**（`x-pick`），同时**收藏**（不会被 48 小时低浏览规则清理）。
  - **改写**：已选素材换成这一条，写作台切到“改写”模式，并打开或切换到写作台标签页。
  - **选入**：加入已选素材（最多 3 条，多篇融合用），按钮显示“已选”；满了时提示。
- 页面结构解析写成独立的纯 DOM 函数（`creation/x-post-reader.js`），用浏览器检查页覆盖中英文界面和截断、引用帖等情况。

## 4. 改写模式（0.31.0）

写作台「成稿」区分两种模式：**按角度写**（现有）和 **改写原帖**。

| 选项 | 取值 |
| --- | --- |
| 改写风格 `RewriteStyle` | 标准改写、钩子开头、X 爆文体、叙事表达、热点快讯 |
| 长度 `RewriteLength` | 接近原文（默认）、约 100／200／300／500／800 字 |
| 形态 | 沿用 `PostFormat`：中短帖观点、引用转发（附原帖链接） |

- **多篇融合**：已选 2～3 条时自动融合观点、去重、按逻辑重组。
- **英文本地化**：原文主要不是中文时，界面显示“将本地化为中文”，提示词要求先理解再用地道中文表达，不逐句直译，专有名词保留原文。
- **改写约束**：不是同义词替换，要用我的人设和视角重组并加入判断；不照搬原文句子；原文里的“我”是原作者，改写时不能冒充原作者的经历。
- **原创度提醒**：每个候选显示与原文的相似度（双字重合，复用发布关联的相似度算法），超过 50% 标黄提醒“与原文过于接近”。英文原文不计算。
- 输出与成稿相同：3 个候选、人设、样本、加权字数、首屏标线、保存草稿、去 X 发布。草稿记录 `rewrite: { style }`，复盘按“改写·风格”分组。
- 模型：使用「成稿」步骤的 API；后台消息由 `step` 改名为 `task`（angles／drafts／rewrite），每个任务声明自己用哪个步骤的 API。

## 5. 对标账号风格（0.32.0）

- 新增「对标风格」页（实现时从写作台独立出来，避免写作台过挤）：从素材库里按作者分组列出 X 帖子，选一位作者的 3～10 条帖子 →「拆解风格」；也可手动粘贴。X 上「选入」在已选满时只收藏，便于收集同一位博主的帖子。
- 模型按 JSON 返回：定位、常写选题、钩子手法（附原句示例）、结构模板、语气与用词、要避免的写法。存为模板（本机，最多 20 个），可改名、编辑、删除。
- 改写和成稿时可选一个模板，提示词带上这些规则；与人设、样本并存（模板管“怎么写”，样本管“像我”）。
- 模型：新增「拆解风格」步骤，可在 AI 设置单独指定。

## 6. AI 配图（0.33.0）

- 编辑区新增「配图」：风格（赛博朋克、3D 盲盒、梗图、冲击、极简、高级、数据涨势、新闻快讯）、比例（16:9、9:16、1:1）。
- 两步：成稿模型根据当前正文写一段出图提示词（可查看、修改）→ 出图模型生成图片。结果可下载、复制，图片只存在本页，不上传他处。
- 出图走 OpenAI 兼容的 `/images/generations` 接口，AI 设置新增「配图」步骤（选任意 API 配置）与出图模型、质量。费用由你的 API 计费，界面提示每次出图会产生费用。参数按 2026-11-17 的 OpenAI 官方接口说明：只返回 `b64_json`；`gpt-image-2` 系列支持任意 宽x高（边长 16 的倍数），更早型号只支持三种标准尺寸；`gpt-image-1` 已停用，默认 `gpt-image-2`。
